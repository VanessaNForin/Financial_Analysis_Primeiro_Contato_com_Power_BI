# 📊 Projeto Power BI — Primeiros Passos

Este projeto foi desenvolvido como parte do desafio do bootcamp **Primeiros Passos em Power BI**, da **DIO**.

O projeto representa meu **primeiro contato com o Power BI**, explorando a criação de visualizações, mapas e análises a partir de dados.

A atividade foi desenvolvida como uma **tarefa prática do bootcamp**, com o objetivo de aplicar os primeiros conceitos aprendidos e conhecer, na prática, os recursos básicos da ferramenta.
